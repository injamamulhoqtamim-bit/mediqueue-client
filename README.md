# 🎓 Teachers Finding Platform

A modern and user-friendly Teachers Finding Platform built with React.js, Vite, and Tailwind CSS.  
This platform helps students easily find suitable home tutors based on subject, budget, and teacher preferences.

The main goal of this project is to create a platform similar to BD JOBS, but focused on finding and booking home tutors in Bangladesh.

## 📌 Project Features

### 👨‍🏫 Teacher Features
- Add tutor profile
- Add teaching subjects
- Set tuition budget/rate
- Delete profile anytime
- Show teacher information dynamically

### 👨‍🎓 Student Features
- Find home tutors easily
- Search teachers by name
- Filter teachers by low/high budget
- Book teachers using:
  - Name
  - Gmail
  - Phone Number
- Cancel booking if needed

### 🔍 Search & Filter System
- Search teachers by name
- Budget-based filtering
- Dynamic tutor listing

### 🌐 Additional Features
- Responsive design for all devices
- Fast performance using Vite
- Clean modern UI with Tailwind CSS
- Live deployed using Vercel

# 🎯 Project Goal

The goal of this project is to build a smart and simple tutor-finding platform where students can easily find qualified teachers and teachers can promote their tutoring services online.

This platform was inspired by the concept of BD JOBS, but specially designed for the education sector and home tutoring system.
